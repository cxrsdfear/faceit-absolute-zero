# Absolute Zero

Тема для faceit.com: свой фон, цвета из картинки, значки уровней, статистика игроков в комнате матча.

## Установка

1. Скачай [FaceitAbsoluteZero.exe](https://github.com/cxrsdfear/faceit-absolute-zero/raw/main/FaceitAbsoluteZero.exe) и запусти.
   Если появится синее окно «Система Windows защитила ваш компьютер», нажми «Подробнее», потом «Выполнить в любом случае».
2. Нажми **«Установить»**. Автообновление включится само.
3. Нажми **«Выбрать браузер»**, выбери свой (рядом с найденными стоит галочка) и нажми кнопку внизу. Откроется страница расширений, путь к папке расширения скопируется.
4. Дальше по шагам для твоего браузера (они же показаны в программе).
5. Открой faceit.com и нажми F5.

Если кнопка не открыла браузер, введи адрес страницы расширений сам (он указан ниже для каждого браузера). Путь к папке:
`%LOCALAPPDATA%\FaceitAbsoluteZero\extension`

### Chrome

1. Адрес: `chrome://extensions`.
2. Справа вверху включи **«Режим разработчика»**.
3. Нажми **«Загрузить распакованное»**.
4. В окне выбора папки вставь путь в строку адреса (`Ctrl+V`), нажми Enter, потом **«Выбор папки»**.
5. Закрепи значок: пазл справа от адресной строки, булавка рядом с «Absolute Zero».

### Microsoft Edge

1. Адрес: `edge://extensions`.
2. Слева внизу включи **«Режим разработчика»**.
3. Нажми **«Загрузить распакованное»**.
4. Вставь путь (`Ctrl+V`), нажми Enter, потом **«Выбор папки»**.

### Opera и Opera GX

1. Адрес: `opera://extensions`.
2. Справа вверху включи **«Режим разработчика»**.
3. Нажми **«Загрузить распакованное расширение»**.
4. Вставь путь (`Ctrl+V`), нажми Enter, потом **«Выбор папки»**.
5. Если Opera пишет, что расширение не из магазина, это нормально: подтверди.

### Brave

1. Адрес: `brave://extensions`.
2. Справа вверху включи **«Режим разработчика»**.
3. Нажми **«Загрузить распакованное»**, вставь путь, выбери папку.

### Vivaldi

1. Адрес: `vivaldi://extensions`.
2. Справа вверху включи **«Режим разработчика»**.
3. Нажми **«Загрузить распакованное»**, вставь путь, выбери папку.

### Яндекс Браузер

1. Адрес: `browser://extensions`.
2. Справа вверху включи **«Режим разработчика»**.
3. Нажми **«Загрузить распакованное расширение»**, вставь путь, выбери папку.

### Firefox

Firefox не ставит расширения не из магазина насовсем, поэтому только временная установка, и после перезапуска браузера её нужно повторять. Тема написана для Chrome, поэтому работа в Firefox не гарантируется.

1. Адрес: `about:debugging#/runtime/this-firefox`.
2. Нажми **«Загрузить временное дополнение…»**.
3. Выбери файл `manifest.json` в папке расширения.

### Если не получается

- Папки `extension` нет: в программе нажми «Установить», подожди надпись «Установлено».
- Кнопка «Загрузить распакованное» не видна: не включён «Режим разработчика».
- Браузер пишет про ошибку манифеста: выбери именно папку `extension`, а не папку выше или внутри.
- После обновления ничего не изменилось: на странице расширений нажми значок обновления у «Absolute Zero» и обнови вкладку FACEIT (`F5`).

**Совет.** Для лучшей работы темы отключи на faceit.com другие расширения, особенно блокировщики рекламы и прочие темы для FACEIT: они меняют те же элементы и могут конфликтовать. Сделать это можно в `chrome://extensions`.

Обновления приходят сами каждые 30 минут. После обновления на сайте появится плашка с тем, что нового.

## Управление и удаление

Запусти `FaceitAbsoluteZero.exe` снова. Там можно обновить вручную, выключить автообновление или удалить всё.
После удаления убери расширение в `chrome://extensions`.

## Если Защитник Windows удаляет тему

Так бывает с программами без подписи. Это ложное срабатывание. Добавь папку темы в исключения — один раз:

1. Открой «Безопасность Windows» → «Защита от вирусов и угроз».
2. «Параметры защиты от вирусов и угроз» → «Управление настройками».
3. Внизу «Исключения» → «Добавление или удаление исключений».
4. «Добавить исключение» → «Папка» и выбери `%LOCALAPPDATA%\FaceitAbsoluteZero`.

После этого запусти `FaceitAbsoluteZero.exe` и нажми «Установить» заново.
