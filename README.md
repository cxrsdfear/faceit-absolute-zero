# Absolute Zero

Тема для faceit.com: свой фон, цвета из картинки, значки уровней, статистика игроков в комнате матча.

## Установка

1. Скачай [FaceitAbsoluteZero.exe](https://github.com/cxrsdfear/faceit-absolute-zero/raw/main/FaceitAbsoluteZero.exe) и запусти.
   Если появится синее окно «Система Windows защитила ваш компьютер», нажми «Подробнее», потом «Выполнить в любом случае».
2. Нажми **«Установить»**. Автообновление включится само.
3. Нажми **«Скопировать путь и открыть папку»**, потом **«Открыть расширения Chrome»**.
4. В Chrome справа вверху включи **«Режим разработчика»**, нажми **«Загрузить распакованное»**, вставь путь (`Ctrl+V`) и выбери папку.
5. Открой faceit.com.

Обновления приходят сами каждые 30 минут. После обновления на сайте появится плашка с тем, что нового.

## Управление и удаление

Запусти `FaceitAbsoluteZero.exe` снова. Там можно обновить вручную, выключить автообновление или удалить всё.
После удаления убери расширение в `chrome://extensions`.
